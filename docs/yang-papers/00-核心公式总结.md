## 一、英文博士论文核心公式 (Appendix B.4)

### 1. FHA 简化模型增益公式

```
Vo     j·ωn·Ql
── = ──────────────────────────────
Vin    j·ωn(Ql+1-1/ωn²) + Ql(1-ωn²)Qs·8/π²
```

**符号定义：**
- `ωn` = fs/fr1：归一化开关频率
- `Ql = Lm/Lr`：两个谐振电感比（即 λ）
- `Zo = √(Lr/Cr)`：特征阻抗
- `Rac = (8/π²)·Ro·n²`：等效负载电阻（半桥+中心抽头）
- `Qs = Zo/Ro`：品质因数（基于输出电阻）

### 2. 等效负载电阻

```
Rac = (8/π²) · Ro · n²
```

### 3. 特征阻抗

```
Zo = √(Lr/Cr)
```

### 4. 两个谐振频率

```
fr1 = 1 / (2π√(Lr·Cr))      ← Lr与Cr的串联谐振频率
fr2 = 1 / (2π√((Lr+Lm)·Cr)) ← 总电感与Cr的谐振频率

关系：fr2 = fr1 / √(1+λ)    其中 λ = Lm/Lr
```

### 5. 空载增益（Region 2，ωn < 1）

```
M = 1 / |1 + 1/λ - 1/(λ·ωn²)|
```

**关键特征：**
- 当 ωn → 1/√(1+λ) 时，M → ∞（理论上）
- 当 ωn = 1 时，M = 1（谐振频率处增益=1）
- 空载时（Q=0），增益曲线在fr2处有奇点

### 6. 从增益反推频率

```
ωn² = G / (G·(λ+1) - λ)

f = fr1 · √(G / (G·(λ+1) - λ))
```

## 二、中文小册子核心要点

### 三个工作区域

1. **Region 1（ZVS区域）**：fs > fr1，类似SRC，Lm被输出电压钳位
2. **Region 2（ZVS区域）**：fr2 < fs < fr1，Lm参与谐振，可获得高增益
3. **Region 3（ZCS区域）**：fs < fr2，应避免的工作区域

### 设计建议
- 工作频率应放在fr1处（400V输入时）
- 输入电压下降时，通过降低频率获得更大增益
- 选择合适谐振参数，使变换器在负载变化或输入电压变化时都工作在ZVS区域

## 四、关键发现：fmax/fmin 公式错误

### 修改前（错误）
```
fmax = fr * √(1 + (1/k)(1 - 1/Gmin²))
```

这个公式来源于对空载增益的错误简化。当G=1时，fn=1是对的，但当G≠1时，推导有误。

### 修改后（正确）
```
fmax = fr * √(Gmin / (Gmin·(k+1) - k))    ← Region 1（fn > 1/√(1+k)），要求 Gmin ≥ k/(k+1)
fmin = fr * √(Gmax / (Gmax·(k+1) + k))    ← Region 2（fn < 1/√(1+k)），分母为 +k
```

推导过程：从标准FHA空载增益公式
```
M = 1 / |1 + 1/k - 1/(k·fn²)|
```
令 M = G，去绝对值有两支解：
```
fn² = G / (G·(k+1) - k)   （分母为正的一支，fn 较大，Region 1）
fn² = G / (G·(k+1) + k)   （分母为负的一支，fn 较小，Region 2）
```

验证：
- G=1 → 两支均给出 fn² = 1/(k+1∓k) → fn=1 ✓（两支在 fn=1 处汇合）
- fmax 用 Region 1 支（高输入电压需压低增益，工作于 fr 以上）
- fmin 用 Region 2 支（低输入电压需提升增益，工作于 fr 以下；若误用 -k 支会得到 Region 1 的较高频率，并非最小频率）

**教训**：v2.1.5 ~ v2.10.x 期间 fmin 曾长期误用 `-k`（Region 1 支），
导致 fmin 被高估约 2 倍以上（如 Gmax=1.2, k=5：错误 fn=0.738 vs 正确 fn=0.314）。

## 四·附、电感比 k 的空载降压约束（勘误）

早期版本（及 v2.1.5 起的核心公式总结）曾使用：
```
G_empty = 1 + 1/k ≥ Gmax  ⇒  kMax = 1/(Gmax - 1)   ❌ 无文献依据
```

正确约束来自 Region 1 空载增益**下限**（fn→∞ 时 M → k/(k+1)，不是 1+1/k）：
```
k/(k+1) ≤ Gmin  ⇒  kMax = Gmin/(1-Gmin)   （仅当 Gmin < 1 时有约束）
```
与 fmax 可行性条件 Gmin ≥ k/(k+1) 完全等价。
文献旁证：《基于时域分析的CLLC谐振变换器参数优化设计》等给出的
k = n·Mmin/(1-n·Mmin) - (1-1/xmax²) 中首项即 Mmin/(1-Mmin)。
